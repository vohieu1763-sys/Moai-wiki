# Moai Wiki — Cục Đá

Website wiki một trang, responsive cho điện thoại, dùng HTML/CSS/JavaScript thuần. Không cần cài thư viện hoặc build.

## Chạy thử
Mở `index.html` bằng trình duyệt. Internet chỉ cần thiết nếu muốn tải font DM Sans/Manrope từ Google Fonts; website vẫn dùng font dự phòng khi ngoại tuyến.

## Deploy bằng GitHub Pages
1. Đăng nhập GitHub và tạo repository mới, ví dụ `moai-wiki`. Với cách dễ nhất, để repository ở chế độ **Public**.
2. Giải nén file ZIP này trên thiết bị.
3. Mở repository vừa tạo, chọn **Add file → Upload files**.
4. Tải lên các tệp và thư mục bên trong `moai-wiki-cuc-da` (đảm bảo `index.html` nằm ngay ở thư mục gốc repository, không nằm trong một thư mục con lồng thêm).
5. Nhấn **Commit changes**.
6. Vào **Settings → Pages**.
7. Trong **Build and deployment**, chọn **Deploy from a branch**.
8. Chọn branch `main`, folder `/(root)`, rồi nhấn **Save**.
9. Chờ GitHub hoàn tất triển khai. Địa chỉ thường có dạng `https://TEN-TAI-KHOAN.github.io/moai-wiki/`. Thay `TEN-TAI-KHOAN` và tên repository bằng giá trị thực tế của bạn.

Nếu dùng repository có tên `TEN-TAI-KHOAN.github.io`, địa chỉ thường là `https://TEN-TAI-KHOAN.github.io/`.

## Cập nhật nội dung
Sửa `index.html` trên GitHub bằng nút hình bút chì hoặc sửa trên máy rồi tải lên lại. Sau khi commit, GitHub Pages sẽ tự triển khai phiên bản mới.
